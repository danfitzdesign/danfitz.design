# danfitz.design

The personal portfolio of Dan Fitzsimmons, designed in Figma and built as a small, responsive static website.

## How it works

- `index.html` contains the page content and document metadata.
- `styles.css` contains the visual design, responsive behaviour, and custom text-selection colours.
- Git records the history of changes.
- GitHub stores the repository online.
- Vercel deploys the latest version of the `main` branch.
- GoDaddy manages the `danfitz.design` domain and its DNS records.

## Run locally

Open `index.html` directly in a browser, or serve this folder with any local static web server.

## Design

The implementation follows four Figma frames: 375 × 900, 768 × 900, 1024 × 900, and 1440 × 900.
